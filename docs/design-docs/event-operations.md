# Event Operations

## Event Types

### Cerita Aja Dulu

Stage-based event with an Indonesian diaspora speaker sharing experience.

Needs:

- title and description draft
- event scheduling
- large-event approval path
- volunteer coverage
- reminder cadence
- post-event summary and content repurposing

### Language Club

Recurring language-learning event in voice channels.

Needs:

- recurring template
- conversation partner coverage
- routine automation path
- attendance and participation summary

### Regional Sharing

Event centered on region-specific diaspora gathering and member interaction.

Needs:

- region-aware channel selection
- participation prompts
- post-event follow-up nudges

## Core Workflow

1. Draft event from template.
2. Classify event as routine or approval-required.
3. Determine required roles and volunteer coverage.
4. Create reminder schedule.
5. Publish event when allowed.
6. Run reminder jobs.
7. Gather attendance and activity signals.
8. Generate wrap-up summary and content queue drafts.

## Routine Vs Large

Routine examples:

- recurring language club
- recurring regional sharing that follows a known template

Large examples:

- Cerita Aja Dulu with a featured diaspora speaker
- non-routine events with new formats or broader announcements

## Operational Pain Points To Solve First

- creating event objects and reminders
- reminding volunteers and conversation partners
- reducing missed coordination before event day
- reducing manual post-event follow-up work
