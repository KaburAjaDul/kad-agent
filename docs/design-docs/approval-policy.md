# Approval Policy

## Principle

Routine low-risk operations may run automatically.

Higher-risk or higher-visibility actions require approval.

## Autonomous

- recurring routine event creation from approved templates
- routine reminder scheduling
- volunteer reminder nudges
- internal weekly analytics summaries
- content queue draft creation

## Approval Required

- large event publication
- non-routine event announcements
- public migration or education answers
- social content ready for publication
- changes to role coverage with unusual or sensitive impact

## Hard Stop

- personal migration recommendation
- legal or visa judgment beyond approved docs
- unsupported claims from memory or web-only sources
- public publishing without queue approval

## Approval Record

Every approval-required action should record:

- action type
- request context
- approver
- approval timestamp
- final execution state
