## When to Use

Use for architecture decisions, library comparison, policy design, and risky feature questions.

## Procedure

1. Define the question clearly.
2. Gather repo evidence first.
3. Use official external docs only where needed.
4. Compare sources and call out contradictions.
5. End with confidence and next action.

## KAD Guidance

- prefer curated internal docs over open-ended web answers
- when safety is involved, cite the exact source doc or policy

## Success Criteria

- [ ] repo evidence is included when relevant
- [ ] contradictions or gaps are explicit
- [ ] answer ends with a recommendation
