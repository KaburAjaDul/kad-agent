## When to Use

Use for planning, scoping, milestone design, and first-slice selection.

## Procedure

1. Define objective and non-goals.
2. List constraints and risks.
3. Break work into meaningful checkpoints.
4. Pick the smallest valuable first slice.
5. Name what still needs approval or evidence.

## Success Criteria

- [ ] milestones have acceptance criteria
- [ ] first slice is bounded and testable
- [ ] approval-sensitive work is separated from routine automation
